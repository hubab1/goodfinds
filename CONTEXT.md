# Goodfinds marketplace shopping

Goodfinds helps a buyer find suitable marketplace listings, compare the evidence and follow up with sellers. These terms describe the same concepts in the panel, tools, skills and storage.

## Language

**Saved search**:
A reusable buying brief with a definition, the buyer's answers and selected marketplaces.
_Avoid_: Watch, search job, buying action

**Search definition**:
The questions, matching rules and comparison dimensions for one buying brief. A search template is a starter definition that can be adapted to the buyer.

**Search run**:
One manual or scheduled execution of a saved search, with query coverage and saved results.
_Avoid_: Search job, scan

**Search worker**:
The background agent currently holding the lease to execute a search run.
_Avoid_: Search owner, queued agent

**Monitoring preference**:
The buyer's choice of one search or recurring checks, including timing and quiet hours.
_Avoid_: Enabled watch, active schedule

**Host schedule**:
The recurring automation registered with the host to wake a group of saved searches. Its observed status is separate from the buyer's monitoring preference.

**Search dispatcher**:
A group of recurring searches in one buying chat that shares a host schedule while keeping each search's timing and outcomes.
_Avoid_: Search worker, shared search run

**Listing observation**:
A dated record of facts inspected on a marketplace listing, with source evidence and uncertainty.
_Avoid_: Row, listing scan

**Listing evaluation**:
A comparison of imported observations against the saved searches and observed peer listings.
_Avoid_: Scan, search run

**Search coverage**:
The observed result counts, query scope and completion evidence from inspecting one marketplace query.
_Avoid_: Collection run

**Search cover**:
A representative illustration for a saved search. It does not provide evidence about a listing.
_Avoid_: Search image

**Seller conversation**:
The buyer's message drafts, observed messages, seller actions and arrangements for one listing.
_Avoid_: Negotiation, offer thread

**Seller action**:
One requested message send or reply check, with its authorization and observed result.

**Message send permit**:
Single-use permission to execute the buyer's exact reviewed message after its identity and duplicate checks.
_Avoid_: Prepared send, claim permission

**Collection plan**:
Proposed or confirmed viewing, pickup, date and demonstration details associated with a seller conversation.

**Buying outcome**:
The buyer-reported result for a listing, such as bought, withdrawn or unavailable. An accepted offer remains a conversation until a purchase is confirmed.
_Avoid_: Negotiation outcome

**Buying next step**:
A suggested verification, message review, reply check or collection action supported by the saved evidence.
_Avoid_: Buying action, automatic offer
