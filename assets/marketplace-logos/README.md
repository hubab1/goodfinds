Facebook's logo is sourced from the primary logo in Meta's official Facebook Brand Asset Pack:

[Facebook brand resources](https://www.meta.com/brand/resources/facebook/logo/)

`facebook.png` is the supplied logo resized to 64 × 64 pixels for the 16-pixel listing source badge. The asset is bundled into the panel, so viewing listings makes no external request for the logo.

The other marketplace icons are the sites' own favicons, bundled locally for both Settings and listing badges:

- [eBay](https://www.ebay.com/favicon.ico): `ebay.png`.
- [Vinted](https://www.vinted.co.uk/): `vinted.png`, from the page's 32-pixel favicon on `marketplace-web-assets.vinted.com`.
- [Gumtree](https://www.gumtree.com/): `gumtree.png`, from the page's favicon at `/assets/frontend/favicon.49f3fbf4ec1a73bc9bf55440eba29ff9.ico`.
- [Auto Trader](https://www.autotrader.co.uk/): `autotrader.png`, from the page's favicon on `m.atcdn.co.uk`.
- [Craigslist](https://www.craigslist.org/favicon.ico): `craigslist.png`.

ICO assets are converted to PNG without changing the artwork. Retrieved on 5 October 2026.
