# Journey checks

Run this pass after provisional discovery and before final ranking when a saved search has a driving-time requirement. It runs in the existing search worker; do not create a schedule or contact sellers to obtain travel evidence.

1. Read `list_goodfinds_journey_checks` for the search. Honor enabled and origin_confirmed; disabled means skip automatic checks, and an unconfirmed origin needs the buyer's confirmation. Manual confirmed origins work as text without coordinates. The queue groups identical displayed towns and excludes listing dismissals and verified banned models. Page through next_offset.
2. Open each maps_url through the selected browser's supported tool. Select driving and verify both endpoints resolve to the intended areas and country. Use the listing's displayed town; do not guess a pickup address. A place with ambiguous matches needs locality clarification. Read the visible route duration: for a range, retain the upper bound. Use the recommended driving route rather than cherry-picking a faster alternative. No screenshot needs to be emitted into chat.
3. Call `record_goodfinds_journey_check` with the returned origin_key, destination, country and listing_keys, visible drive_minutes, precision town, the checked Google Maps directions source_url, an excerpt establishing endpoints and duration, and the actual check time. Use estimate_kind traffic for a current route; typical requires an explicit usual/typical travel-time indication. The server stores the route on the user's device and applies it to existing and future listings in that town without changing their fact, price or availability timestamps.
4. Cached traffic estimates last 24 hours; explicitly typical estimates last seven days. Origin or displayed destination changes invalidate reuse. Close-to-limit town estimates remain conditional: confirm the pickup area at the agreement/collection stage before committing. Display “About 40 min drive · town-level estimate”, retaining check time and source. Never equate a town centre with the exact pickup.
5. If Maps is unavailable, challenged or cannot resolve a place, preserve unknown driving time and record the specific interruption in the search run's next_step/interruption. Do not invent a route from straight-line distance, repeatedly retry the same blocked route, or label a known town as missing location. The buying chat can report that routes remain unchecked without exposing intermediate screenshots.

Settings offers Google Maps with local cache or Off. Google receives the chosen origin and destination through the user's browser. The plugin requires no routing account, API key or developer-operated server. No shared routing key or public geocoder is embedded. Fully offline routing needs a local engine and downloaded map data; it is not supplied by this browser workflow.
