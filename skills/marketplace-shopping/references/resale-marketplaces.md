# Poshmark, Depop and Mercari

Use this guide for `poshmark` (US), `depop` (US/UK), or `mercari` (US). Country/category/fulfilment recommendations are curated; do not expand regional scope because another website exists. Preserve saved marketplace choices and explicit currencies. These are delivery-oriented defaults; a listing needs its own collection/delivery evidence.

When collecting or refreshing listing status, apply [availability evidence](availability-checks.md#marketplace-evidence). Every scheduled run rechecks saved listings through that guide before discovery; distinguish sold items from temporarily paused purchasing.

## Search once in the correct region

| Source      | Search                                                            | Canonical listing and `listing_id`                                                |
| ----------- | ----------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| Poshmark US | `https://poshmark.com/search?query=<encoded query>&type=listings` | `/listing/<slug>-6577c0f3ac1f7629f1c445fe` → final 24 hex characters              |
| Depop US/UK | `https://www.depop.com/search/?q=<encoded query>`                 | `/products/pxague_szn-nike-cream-hoodie-size-xxl-f2d2/` → the entire product slug |
| Mercari US  | `https://www.mercari.com/search/?keyword=<encoded query>`         | `/us/item/m32963257828/` → `m32963257828`, including `m`                          |

Use Depop's footer **Select Location** control to confirm United States or United Kingdom before searching. Changing it can clear the query and return generic results: re-enter the requested query, then wait for its results heading. The UK home is `/gb/`; the shared search URL does not encode the selected country. Opening the US home alone can retain UK results. A seller's original currency can differ from the search country; a US listing viewed in the UK can correctly show `US$`, without establishing cross-border delivery.

On Mercari, exclude the separate Japan destinations (`jp.mercari.com`, `japan.us.mercari.com`); do not substitute Japan inventory for US search. Inspect Status/availability because default results may include SOLD cards. On Poshmark, verify the Available Items filter. Reject wanted/ISO advertisements as buying candidates even if they have a numeric price.

Apply the buyer's category, brand, size, condition and price preferences through visible controls. Read cards with their actual hrefs; repeated generic titles are common. Open the selected card's observed detail href with full browser navigation, then wait for its heading. This gives media tools a fresh detail document. Client-side card clicks can leave the export inventory describing search thumbnails even though the listing DOM has changed. Following one browser-adapter failure, inspect the current state and use that already-observed detail URL; do not guess alternative routes.

After a click or `setChecked` error, re-read checked state, chips and settled results before retrying. The intended filter may already be applied. Continue when applied; retry once only when the observed state still lacks the selection, then record any remaining limitation.

- On Poshmark, finish department and category selection first (for example Men → Shirts → Sweatshirts & Hoodies), then apply brand and size. Category changes can clear those filters. Wait for each navigation to settle and verify the final category, brand, size and availability. Its styled brand checkboxes can hide the input: click the associated visible label and verify checked state instead of repeatedly clicking the input. Use the label's observed attribute exactly: `data-test` requires an attribute selector, while `getByTestId` targets `data-testid`.
- On Depop, clothing filters nest category and subcategory (for example Men → Tops → Hoodies), and size under the applicable clothing group and sizing system. Confirm the selected chips before opening a result. Combine independent, already-observed controls in one bounded browser call; wait for result navigation before the next dependent selection.
- On Mercari, select the item category before its size group; regular XXL and Big & Tall sizes are distinct. Scope category controls to the observed category list and match **Men** exactly, since substring matching also selects **Women**. Apply **For sale** when available. If the relevant sidebar exposes no brand control, use the query and the listing's explicit brand field, and record that no native brand filter was applied.

## Extract the item price and detail

- **Poshmark:** distinguish the current price from a struck-out original price and instalments. Save shipping separately. Read the description even if it repeats the title. Exposure hashtags can list unrelated sizes, brands and colours; use item fields and explicit item claims for attributes. An original retail price does not establish market value.
- **Depop:** wait for **Price breakdown** to load after the heading, then store item price, shipping, fee and tax separately. The headline may include these costs. A displayed tax/shipping estimate without a confirmed buyer destination does not establish final payable cost; keep `costs_complete: false`. Preserve the displayed currency and scope extraction above **You might also like**. Read the seller name/profile from the page: the product slug can contain a different name. Keep seller location unknown if absent.
- **Mercari:** distinguish current price, previous price, Buyer Protection fee, shipping and instalments. Read the shipping markup: the discounted amount is current; an amount inside `s` is the old price. Use the **Delivery From** location when shown, without inferring a city from a state label.

Capture canonical identity, title, availability, item price/currency, cost breakdown, description, condition, size/brand/colour/material when stated, location, seller and source excerpts in one observation. Sold items are not active. Preserve unknown facts instead of filling them from the search's region. Seller sold totals, reviews and followers are not current inventory counts. Do not collect last-active information. A public Buy/Offer/Ask button does not establish authenticated contact availability.

## Media and readback

Follow [listing evidence](listing-evidence.md). When all main gallery sources are loaded, match them to the documented page-assets inventory and export one batch. Retain the ordinal-to-source/file map. Use sequential element downloads when the inventory does not contain the gallery.

If a listing reached through a client-side transition has loaded gallery sources missing from inventory, reload the current detail page once, wait for its heading/gallery, and reacquire the inventory before exporting. Mercari's six-photo gallery reproduced a one-of-six inventory after a result click; one reload restored all six. This is a bounded recovery for stale media state, not a reason to repeatedly reload or navigate to asset URLs. If a download still fails, save the working files and report partial capture instead of repeating the same failing method for every remaining photo.

- Poshmark photo labels expose `Picture N of M`. Select each lazy position with **next** and use a bounded load check for its nonempty source and natural dimensions. An immediate empty source is still loading. Once all positions are loaded, export the matched assets together; otherwise save the loaded positions and record partial capture. Avoid full-page snapshots containing payment-frame markup when a focused main-content read suffices.
- Depop exposes the seller's item images separately from recommendations and the avatar. Image labels can change while the page loads: inspect the current gallery DOM `img` alt/source values immediately before export, instead of reusing an earlier product-title label. Scope inspection to the observed gallery container and its position labels; the browser's read-only DOM wrapper does not implement `compareDocumentPosition`. Responsive layouts can retain hidden copies of the same gallery positions, including unloaded copies. Use the displayed gallery to identify positions and loaded sources; a hidden duplicate is not an extra photo or a reason to wait for every page image. If duplicate inspection is needed, use observed DOM selectors; accessibility role locators exclude hidden images. Preserve actual lazy or carousel positions and load those separately when needed. Map the gallery sources to the inventory; use the observed DOM selector for an unmatched slot. Preserve gallery ordinals and review any seller video separately if present.
- Mercari renders both preview thumbnails and main images with numbered labels. Choose the main item images and count each source slot once. Browser downloads may be AVIF; Goodfinds supports their actual content type.

Save partial progress with expected gallery totals and failure notes. Use the returned listing key and canonical URL for readback; URL normalization can remove a trailing slash. Read back description, price/currency/fees, location, seller fields and each cached ordinal. Mark capture complete only when every observed photo/video slot is saved; mark visual review complete only after actual inspection. Keep a missing location explicitly unknown. Do not open checkout or send seller messages as an extraction test.
