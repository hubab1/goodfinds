# Panel and chat actions

The panel and agent share one backend. Persistent panel changes call the same MCP mutations available in chat; the local preview routes those tool calls to the same service. Use scoped entity revisions for persisted edits and the conversation's `version` for buying actions; follow [tool contracts](tool-contracts.md) for retries and conflicts. A successful mutation updates durable state for either interface; the panel refreshes it without a separate edit.

| Buyer intent                                                           | Tools                                                                                                                                                                        |
| ---------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Read/change settings, area, browser or marketplaces                    | `get_goodfinds_settings`, `save_goodfinds_settings`; `open_goodfinds_location_chooser` for the device location chooser                                                       |
| Change quiet hours, time zone or default check frequency               | `save_goodfinds_settings` with `quiet_hours` or `interval_minutes`; reconcile active host recurrences through evaluation-delivery.md                                         |
| Create/edit a search or resume its draft                               | `get_goodfinds_search_context`, `list_goodfinds_search_templates`, interview tools, `save_goodfinds_search_draft`, `save_goodfinds_search`, `discard_goodfinds_search_draft` |
| Search now, stop or resume                                             | `request_goodfinds_search_run`, native background dispatch, `cancel_goodfinds_search_run`; follow background-work.md                                                         |
| Pause/resume monitoring, change frequency or remove a search           | `set_goodfinds_monitoring`, `set_goodfinds_search_enabled`, `remove_goodfinds_search`; reconcile the linked host schedule through evaluation-delivery.md                     |
| Set specific daily times or allow overnight checks for one search      | `set_goodfinds_monitoring` with `timing: {mode: "daily", times: [...]}` or `allow_quiet_hours`; use the returned compiled plan                                               |
| Check an automatic wake-up before dispatch                             | `check_goodfinds_scheduled_search`; normal skips return quietly; automatic starts pass trigger `scheduled`                                                                   |
| Choose/remove a representative search cover                            | `set_goodfinds_search_cover`; cache or choose an existing cover first                                                                                                        |
| Show all listings, promising options or good deals                     | `list_goodfinds_listings` with `result_type` set to `all`, `promising` or `good_deals`, optional `search_id`, `seller_filters`, and sort                                     |
| Read a listing, seller details or its history                          | `get_goodfinds_listing`                                                                                                                                                      |
| Show a saved photo or video                                            | `get_goodfinds_image` for native image output; `get_goodfinds_media_file` for a verified local photo/video path without encoded video bytes                                  |
| Disregard a listing, explain a preference or restore it                | `record_goodfinds_listing_feedback`, `undo_goodfinds_listing_feedback`; preserve the buyer's original wording and scope                                                      |
| Read activity, monitoring or running searches                          | `list_goodfinds_activity`, `get_goodfinds_monitoring`, `list_goodfinds_search_runs`                                                                                          |
| Check marketplace connections or stop a check                          | `start_goodfinds_connection_check`, `get_goodfinds_connection_check`, `cancel_goodfinds_connection_check`; delegate through background-work.md#connection-checks             |
| Manage drafts, replies, collection plans or bought/not-bought outcomes | Conversation tools through seller-conversations.md and buying-follow-through.md; retain exact reviewed-send requirements                                                     |

`list_goodfinds_listings` filters before pagination. Seller filters use `minimum_listings`, `maximum_listings` and a `joined_by` year. Omit a limit for Any. Unknown/stale counts cannot establish a requested range; lower bounds establish only limits they prove. Disregarded items stay hidden unless `include_dismissed: true`. Price sorting groups currencies and rent periods rather than comparing unlike amounts. Use `get_goodfinds_listing` when an individual item's evidence is needed.

Tab changes, expanded sections, carousel position and unsaved form text are local presentation. An agent can read the corresponding information or save the same final change without operating those controls. Device location permission and external sign-in still use their supported host/browser flows. Saved video transport remains app-only to keep large encoded files out of model context; its agent equivalent returns the managed local file, which local hosts can preview. For hosts without file access, playback remains in the panel.
