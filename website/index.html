A few things to know before you start

Installed packages include the server and interface, with no Bun or Node installation needed. Browser actions require compatible host tools. Automatic checks and alerts need a configured host schedule, an awake device and a running host app.

Searches, evidence and conversations are stored locally. Connected browsing and AI use your host app’s services and settings. You review seller messages before sending; Goodfinds does not buy items for you.
